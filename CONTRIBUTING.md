# Contributing

Thank you for improving **NextDNS Skills**. The complete contributor guide is maintained in [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md), including rule authoring, manifest registration, generated `AGENTS.md` output, validation commands, pull-request evidence, and zero-PII requirements.

Before editing, read [AGENTS.md](AGENTS.md) and choose the matching procedure in [.agents/workflows/](.agents/workflows/). For public documentation changes, also read [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md).

All contributions should explain the problem they solve, identify the canonical source of truth, include relevant validation evidence, and use safe placeholders instead of live account data.
